# ML System Design — The Complete Interview & Engineering Guide

> **68 questions · 10 topics · 10 end-to-end design cases** — structured, opinionated, and deep. Built for ML system design interviews *and* for engineers who have to actually run these systems in production.

---

## What this repo is

Most ML content teaches models. This repo teaches **the system around the model**: data pipelines, feature stores, serving infrastructure, monitoring, deployment strategies, cost and security — the ~80–90% of a production ML system that isn't the model.

Every question gets:
- A **direct answer** you can give in the first 30 seconds
- **Depth** — decision tables, architecture diagrams, trade-offs, failure stories
- An **"interview sound bite"** — the compressed version to deliver out loud
- A **cross-referenced trail** into related questions, because real systems don't have chapter boundaries

The theory chapters ([01.md](01.md)–[09.md](09.md)) each end with a self-test checklist. The case chapter ([10.md](10.md)) runs ten complete design interviews through one reusable skeleton. [10_Summary.md](10_Summary.md) compresses everything into a cheat sheet, glossary, and master checklist.

## Core architecture reference (the one diagram behind all ten cases)

**End-to-end lifecycle:**

```
Data Sources → Data Ingestion → Data Storage → Data Processing → Feature Engineering
     → Training Pipeline → Model Evaluation → Model Registry → Model Deployment
     → Inference → Predictions → Monitoring → Retraining → (back to Training)
```

**Online serving path:**

```
Client → Load Balancer → API Service → Feature Retrieval → Model Server → Prediction → Response
```

Full detail and narration: [02.md](02.md) Q8 and [05.md](05.md).
